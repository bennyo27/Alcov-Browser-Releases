# Alcov Desktop releases

Public downloads and update metadata for Alcov, the desktop browser with agents built in.

Application source stays private; this repository holds release artefacts only.

- Download the latest Linux build from the [releases page](https://github.com/bennyo27/Alcov-Browser-Releases/releases/latest).
- `latest-linux.yml` is the electron-updater feed for this repository.

Linux x64 AppImage: mark it executable (`chmod +x Alcov-*-linux-x86_64.AppImage`) and run it. The build is currently unsigned.
